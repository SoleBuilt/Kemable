The first preview of Kemable for Windows: a fast, light database client.

- SQLite, PostgreSQL (also Neon and Supabase), SQL Server, Redis and Cloudflare D1, with RabbitMQ and Firebase as previews.
- Results stream into a grid that scrolls millions of rows; sort and filter them in the app.
- Browse and edit tables, with the statements shown before they run.
- Live tabs that listen to PostgreSQL, Redis, Supabase Realtime, RabbitMQ and Firebase.
- SSH tunnels, saved connections with passwords in Windows Credential Manager, `.sql` files and folders.
- Updates in place: each launch asks GitHub once whether a newer version exists, and installs it when you choose Update.
