# Trademark policy

The code in this repository is licensed under the [AGPL-3.0-only](LICENSE). That
license covers the code. It does not cover the names **Kemable** and
**SoleBuilt**, or the Kemable icon and logo, which identify the builds this
project publishes. Section 7(e) of the AGPL allows a project to keep these out of
the license; this file says what you may do with them.

The aim is simple: anyone who gets something called Kemable gets the app this
project ships, not a build someone else changed.

## What you can do

- Build Kemable from this source for your own use, changed or not.
- Share an official release unchanged, for example through a package manager,
  under the name Kemable.
- Package the unchanged source for a package manager or an operating system
  under the name Kemable, with only the changes packaging needs.
- Say in plain words that your work is based on Kemable, works with Kemable, or
  is a fork of Kemable, in a way that does not suggest it is Kemable.
- Use the name and the icon to write about Kemable, review it, teach it, or link
  to it.

## What needs another name and icon

- A build with any other change: new or removed features, premium features
  unlocked, a license check removed, or other branding. Rename it and replace the
  icon before you share it.
- A product, company, domain, app store listing, or package name that people
  could take for Kemable, for SoleBuilt, or for something this project made.
- Anything that suggests this project endorses, sponsors, or supports your work
  when it does not.
- Selling Kemable, or builds of it, under the Kemable name.
